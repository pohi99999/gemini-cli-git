# Output Directory

This directory stores artifacts generated by the `example_skill`.

## Purpose

- Generated content from scheduled demands
- On-demand task outputs
- State files (e.g., `.last_commit_hash`)

## Structure

Organize your outputs based on your use case:
- By date: `YYYY-MM-DD-description.md`
- By type: `reports/`, `analysis/`, `content/`
- By platform: `linkedin/`, `medium/`, `docs/`

## Git Tracking

Output files are tracked in Git and become part of the agent's memory. This enables:
- Version history of generated content
- Learning from past outputs
- Continuity across executions
