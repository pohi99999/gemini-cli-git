# Gemini CLI Daily Tips

This directory contains daily tips generated from analyzing the [Gemini CLI](https://github.com/google-gemini/gemini-cli) repository.

## About

Each day, the agent analyzes the Gemini CLI repository and generates a practical tip covering:
- CLI commands and usage patterns
- Configuration options and best practices
- MCP server integrations
- Extension system and available extensions
- Advanced features and customization
- Productivity tips and workflow optimizations
- Integration patterns with development workflows

## File Format

Tips are saved as:
- `YYYY-MM-DD-tip.md` - Daily tip for that date
- `tip-history.json` - Metadata tracking covered topics

## Latest Tips

Tips will appear here as they are generated by the scheduled demand.
